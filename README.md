# Proof Dungeon：証明と反証の迷宮

自然演繹による証明の組み立てと、反例（真理値の割り当て・Kripke 模型・構造）による証明不可能性の確認を、迷宮のパズルとして体験するブラウザゲームです。

- 手持ちの鍵（仮定）を使って扉（証明の目標）を開けると、操作がそのまま自然演繹の証明図になります。
- 命題論理から一階述語論理、等号、集合、群、自然数と帰納法まで、全 20 ワールド・109 ステージがあります。
- 証明できない推論は、反例を作って示します。

## 遊び方

ブラウザで `index.html` を開くだけで遊べます（インストールは不要です）。
画面右上の「遊び方」と「チュートリアル」で、操作の説明を見られます。

クリアの記録は、遊んでいるブラウザの中に保存されます。
