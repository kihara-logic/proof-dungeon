# Proof Dungeon：自然演繹の迷宮

自然演繹による証明の組み立てと、反例（真理値の割り当て・クリプキモデル・構造）による証明不可能性の確認を、迷宮のパズルとして体験するブラウザゲームです。

- 手持ちの鍵（仮定）を使って扉（証明の目標）を開けると、操作がそのまま自然演繹の証明図になります。
- 命題論理から一階述語論理、等号、集合、群、自然数と帰納法まで、迷宮は 19 の層と隠し層（全 111 ステージ）からなります。層は、前の層をクリアすると順に開きます（「制限なしモード」ですべて開きます）。
- 証明できない推論は、反例（真理値の割り当て・クリプキモデル・構造）を作って示します。
- 各層の最後にある「書庫」には、その層で使う自然演繹の推論規則を数学として解説した書物が並んでいます（全 26 冊）。
- 「Lean モード」をオンにすると、同じ証明が定理証明支援系 Lean 4 のコードとして書かれていきます。
- 日本語と英語に対応しています。

## 遊び方

ブラウザで `index.html` を開くだけで遊べます（インストールは不要です）。
画面右上の「遊び方」と「チュートリアル」で、操作の説明を見られます。

クリアの記録は、遊んでいるブラウザの中に保存されます。
